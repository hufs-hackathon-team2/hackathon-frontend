# 스티커 목록 (LLM 선택지)

PLUS Log 내용을 읽고 아래 `name` 중 하나만 고릅니다.
목록에 없는 이름을 만들어내면 앱에서 기본 스티커로 대체됩니다.


## 권장 규칙

1. 구체적인 행동이 있으면 행동을 고른다 (감정보다 우선)
2. 비슷한 게 여럿이면 더 구체적인 쪽을 고른다
3. 목록에 없으면 sparkles
